# Security policy

This project is pre-1.0. Security fixes land on `main` and ship in the next patch release; run the latest release before reporting.

Report privately through GitHub's [private vulnerability reporting](https://github.com/rey-obejero/ai-chat/security/advisories/new). Never open a public issue or pull request for a vulnerability.

In scope: authentication and session handling, authorisation between users, the media proxy (SSRF), prompt injection, and rate-limit bypass.
